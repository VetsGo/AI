# PR4

bot.py - головний файл, який запускає всю програму

config.py - файл конфігурації, який містить основні налаштування бота

database.py - відповідає за взаємодію з базою даних SQLite

handlers.py - обробляє всі взаємодії з користувачем

keyboards.py - створює всі клавіатури, які використовуються в боті

states.py - визначає стани при яких бот очікую відповіді користувача

utils.py - файл для отримання поточного курсу валют від API ПриватБанку та погоди від API OpenWeather
