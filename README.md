# AI

Реалізував усі основні функції бота: каталог товарів, кошик, оформлення замовлення, система оплати, користувацький інтерфейс. Також можна подивитися погоду на сьогоднійшній день. Було використано три таблиці з бази даних: customers - зберігає користувачів, orders - зерігає замовлення, cars - містить в собі автомобілі, які купуватиме користувач.
